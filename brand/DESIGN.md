# AI 컨설팅 제안서 디자인 초안

## 디자인 목표

복잡한 AI 내용을 쉽게 이해할 수 있는 차분하고 신뢰감 있는 제안서를 만든다. 화면을 꾸미는 것보다 핵심 메시지, 근거, 실행 순서가 먼저 보이게 한다.

## 전체 분위기

- 전문적이지만 딱딱하지 않은 인상
- 충분한 여백을 사용한 단정한 화면
- 기술을 과장하는 미래적 장식은 최소화
- 표와 도식은 설명에 꼭 필요한 경우에만 사용

## 색상 방향

아래 색상은 시작점이며 고객 환경에 맞춰 조정할 수 있다.

- 기본 배경: 흰색 또는 매우 밝은 회색
- 기본 글자: 짙은 남색 또는 짙은 회색
- 주요 강조색: 선명한 파랑 계열 한 가지
- 보조 강조색: 청록 또는 연한 파랑 계열 한 가지
- 경고나 위험: 붉은색을 필요한 부분에만 제한적으로 사용

한 슬라이드에서 많은 강조색을 함께 사용하지 않는다.

## 글꼴과 글자 크기

- 한글과 숫자가 또렷하게 보이는 고딕 계열 글꼴 사용
- 표지 제목: 42pt 이상
- 슬라이드 제목: 32pt 이상
- 본문: 17pt 이상
- 작은 출처 표기: 읽을 수 있는 범위에서 최소화

특별한 이유가 없으면 한 문서에서 두 종류 이상의 글꼴을 섞지 않는다.

## 화면 구성

- 표지는 제목, 짧은 설명, 날짜 정도만 배치한다.
- 본문은 한 개의 중심 메시지를 기준으로 구성한다.
- 작은 상자를 여러 개 나열하는 화면은 피한다.
- 비교가 필요하면 두 영역으로 단순하게 나눈다.
- 단계가 중요하면 번호와 짧은 설명으로 순서를 보여준다.
- 표는 행과 열을 최소화하고 중요한 값만 강조한다.

## 이미지와 도표

- 내용과 직접 관련된 이미지에만 공간을 사용한다.
- 장식용 아이콘을 반복해서 사용하지 않는다.
- 같은 이미지를 여러 슬라이드에 반복하지 않는다.
- 데이터 차트는 축, 단위, 기간, 출처를 표시한다.
- 복잡한 구조도는 읽는 순서가 명확하도록 단순화한다.

## 문장 작성 방식

- 제목은 슬라이드의 실제 주제를 직접 적는다.
- 한 문장은 짧게 쓰고 불필요한 수식어를 줄인다.
- 근거 없는 홍보 문구와 과장된 표현을 피한다.
- 기술 용어에는 쉬운 설명을 붙인다.
- 결론과 근거가 구분되어 보이게 한다.

## 확인이 필요한 항목

- `[확인 필요]` 고객이 선호하는 색상
- `[확인 필요]` 사용 가능한 로고 파일
- `[확인 필요]` 공식 글꼴 사용 여부
- `[확인 필요]` 발표 화면 비율과 출력 필요 여부
- `[확인 필요]` 참고할 기존 제안서 또는 문서
